一、安装依赖------------pip install -r requirements.txt二、启动程序------------Windows：  双击 StartQuarkTool.batMac / Linux：  python -m quark_batch_tool三、登录账号------------1. 启动后点击「账号管理」2. 选择「扫码登录」或「手动粘贴 Cookie」3. 登录成功后会自动保存登录态四、功能说明注意：在文件管理界面勾选操作类型后 才能使用以下功能！！！所有任务的功能延时 至少调到5秒以上 避免给服务器带来巨大压力！！！雪崩的时候没有一片雪花是无辜的！！！------------- 文件管理：浏览、搜索、勾选网盘文件- 批量分享：勾选文件后统一创建永久分享链接，可导出 Excel- 批量转存：输入分享链接或导入 Excel 批量转存文件 同时应该输入转存目标地址的FID（在文件管理界面中有FID列，请自行查看）- 批量复制：勾选文件批量复制到指定文件夹
