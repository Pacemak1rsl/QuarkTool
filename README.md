# Quark Batch Tool

夸克网盘批量管理工具原型。

## 免责声明

本项目仅供学习和研究使用，基于逆向工程分析夸克网盘的接口实现。使用本工具可能违反夸克网盘的服务条款，请自行承担使用风险。开发者不对因使用本工具导致的任何后果负责，包括但不限于账号封禁、数据丢失等。请在遵守当地法律法规的前提下使用本工具。

## 当前能力

- 扫码登录或手动粘贴 Cookie，并保存登录态
- 文件管理页：刷新目录、搜索、勾选文件
- 文件管理页会显示文件/文件夹 FID
- 批量分享：文件加入批量分享工作台后统一创建永久分享，并可导出 Excel
- 批量转存：在单独工作台内批量输入分享链接，或导入包含“游戏名/夸克链接/文件名称”的 Excel；可逐行填写转存地址 FID，转存后自动分享并导出新链接 Excel
- 批量复制：可勾选多个文件/文件夹加入“被复制”，再勾选多个文件夹加入“复制到”
- 任务队列：每个批量操作前随机等待，默认 5-10 秒
- 分享链接默认永久有效

夸克网盘没有公开稳定 API，接口可能变化。首版把核心流程封装好了，但“云端复制”接口需要登录后用真实账号验证一次。如果接口返回参数错误，可以根据日志再修。
